# stampchord

Stamp encode/decode helpers for chord payloads in pipelines.

**Site:** https://theworker02.github.io/stampchord/

## Install / run

```bash
git clone https://github.com/theworker02/stampchord.git
cd stampchord
node src/cli.js
node --test
```
